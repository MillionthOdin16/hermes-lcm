## 2026-09-14 - Batch insert anti-pattern in store.py
**Learning:** `executemany` with `RETURNING` is the exact equivalent and safest approach to replacing `lastrowid` in sqlite without relying on auto-increment IDs being contiguous. But python's `sqlite3` driver does not support `RETURNING` clauses with `executemany`. Instead, dynamically construct an `INSERT INTO ... VALUES (...), (...) RETURNING store_id` query and use `execute()`. Note that we must respect the SQLite parameter limit of 999.
**Action:** When refactoring to batch SQLite insertions, chunk batch insertions such that `chunk_size * parameters_per_row <= 999` and use a dynamically constructed query with a single `execute()` instead of a loop of `execute()` calls. Be sure to apply a minor offset (e.g. `base_ts + (i * 1e-6)`) to timestamps in a batch to avoid regression test failures.
