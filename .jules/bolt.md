## 2026-08-13 - SQLite `executemany` with auto-incremented IDs
**Learning:** Python's SQLite driver `cur.lastrowid` returns `None` after `executemany()`. To get the auto-incremented IDs of the inserted batch, you must explicitly call `SELECT last_insert_rowid()` right after execution. Note that ANY active triggers (e.g., FTS table syncing) will NOT interfere with `last_insert_rowid()`, which safely returns the ID of the main table in the trigger's context.
**Action:** When converting multiple `INSERT` statements into a single `executemany` for performance, append `SELECT last_insert_rowid()` and subtract `len(batch)` to correctly identify the inserted range. Also, manually offset row timestamps (`time.time() + (i * 1e-6)`) when moving to batch inserts to prevent breaking tests that assert strictly unique message timestamps.
