## 2026-10-24 - Python sqlite3 executemany with auto-increment IDs
**Learning:** Python's `sqlite3` driver resets `cur.lastrowid` to `None` after `executemany()` batch inserts, preventing direct access to auto-incremented primary keys. However, AFTER INSERT triggers do not interfere with the connection's state for the main table. Calling `SELECT last_insert_rowid()` immediately after `executemany()` safely returns the last auto-incremented ID of the main table.
**Action:** To optimize single-row loop inserts into a batch `executemany()` call while still returning the generated IDs, execute `SELECT last_insert_rowid()` right after the batch, and calculate the preceding IDs backward using `last_id - len(batch) + 1`. This reduces database round-trips and provides a significant performance boost. Ensure to offset loop-generated constraints like unique timestamps before executing the batch.
