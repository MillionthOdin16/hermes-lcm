## 2026-05-18 - SQLite Batch Insert Overhead
**Learning:** In Python's sqlite3 module, looping and calling `execute()` for each message in a large batch is extremely slow (O(N) Python-to-C API transitions and statement parsing). Using dynamically constructed `INSERT INTO ... VALUES (...), (...) RETURNING store_id` cuts down insertion time significantly (e.g. ~4.2x speedup for 5000 rows). However, the maximum number of parameters in a single SQLite query defaults to 999. Since each message takes 14 parameters, the batch must be chunked (e.g., max 70 rows per query).
**Action:** Always batch multi-row inserts using parameterized `VALUES (...), (...)` clauses instead of a Python `for` loop, ensuring to chunk rows to respect the 999 parameter limit and utilizing `RETURNING id` to retrieve auto-incremented primary keys correctly.
