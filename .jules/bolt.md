## 2026-08-30 - [Optimize Store Message Batching]
**Learning:** Python's `sqlite3` driver sets `cur.lastrowid` to `None` after `executemany()`. To retrieve auto-incremented IDs for batch inserts without a `RETURNING` clause, execute `SELECT last_insert_rowid()` immediately after the batch insert to get the last inserted ID, then calculate the preceding inserted IDs backward using `cur.rowcount` or `len(batch)`. Also, the codebase enforces a regression constraint where each message row must receive a strictly unique timestamp. When using `executemany`, apply a minor offset (e.g., `time.time() + (i * 1e-6)`) to ensure uniqueness.
**Action:** Replace `execute` in loops with `executemany` for batch inserts, apply small offsets for timestamps, and calculate IDs backward from `last_insert_rowid()`.
