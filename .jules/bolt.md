## 2026-04-18 - SQLite Batch Insert Last Row ID Pattern
**Learning:** Python's `sqlite3` driver resets `cur.lastrowid` to `None` after `executemany()` calls. You cannot rely on `cur.lastrowid` for retrieving IDs when doing batch inserts without a `RETURNING` clause. Furthermore, each message in the batch must maintain a strictly unique timestamp offset so tests don't break.
**Action:** When performing batch inserts with `executemany()`, immediately follow it with `SELECT last_insert_rowid()` to obtain the ID of the last inserted row. Then, use the length of the batch to compute the contiguous range of allocated IDs sequentially. Also ensure to compute parameters in a loop before the DB call, adding a small offset to the timestamp (e.g. `time.time() + (i * 1e-6)`) to guarantee uniqueness per row.
